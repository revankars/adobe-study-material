📚 Domain 1: Planning & Strategy (8 Questions, 26% of exam)
Q1: Business KPI Alignment
An e-commerce company wants to increase customer lifetime value (LTV). Which success metric should be PRIMARY?
  • A) Number of times "Add to Cart" button clicked
  • B) Total sessions from returning visitors
  • C) Revenue per visitor (RPV) across all visits
  • D) Average rating on product pages

✓ Correct Answer: C) Revenue per visitor (RPV) across all visits

Explanation: LTV is about monetary value over time. RPV directly measures revenue per visitor across all visits, aligning with the LTV goal.
Q2: Hypothesis Construction
A SaaS company observes that visitors reaching the pricing page have 12% signup rate, while those not reaching it have 0%. They want to test moving pricing above the fold. Which hypothesis best represents this?
  • A) "If we move pricing above the fold, then visitors will click more links, because pricing is visually prominent"
  • B) "If we move pricing above the fold, then free trial signups increase by 20%, because visitors who see pricing earlier are more likely to convert"
  • C) "If we show discounts on pricing, then revenue increases, because discounts drive purchases"
  • D) "If we update the pricing page design, then page load speed improves, because simplified design loads faster"

✓ Correct Answer: B)

Explanation: Strong hypotheses have three components: ACTION (move pricing), OUTCOME (increase by 20%), and REASONING (earlier visibility → more conversions). This directly addresses the business observation with testable prediction.
Q3: Activity Type Selection
Three distinct audience segments need uniquely tailored messaging. Each segment receives specific message. No statistical comparison needed. Which activity type?
  • A) Automated Personalization (AP)
  • B) Multivariate Test (MVT)
  • C) Experience Targeting (XT)
  • D) Auto-Target

✓ Correct Answer: C) Experience Targeting (XT)

Explanation: XT maps specific audiences to specific experiences without statistical comparison. Perfect for predefined audience-to-message mappings.
Q4: Sample Size Criticality
A/B test requires 8,000 visitors per variation. After 1.5 weeks: 4,000 visitors per variation collected. Variation shows 12% lift, 88% confidence. What to do?
  • A) Declare winner; 88% confidence exceeds 85% threshold
  • B) Continue until 8,000 per variation; early stopping increases false positive risk
  • C) Stop and implement original; only 50% sample complete
  • D) Run one more week for preliminary validation

✓ Correct Answer: B)

CRITICAL RULE: MUST reach calculated sample size BEFORE declaring winner. Sample size + 95% confidence are BOTH required (non-negotiable). This prevents false positives.
📌 Exam Insight: Sample size is #1 way practitioners make false positive errors. Expect multiple questions about this.
Q5: Audience Attribute Selection
Luxury fashion site analyzed data: Annual income (STRONG correlation with purchase value), Mobile vs desktop (WEAK), Time since purchase (MODERATE), Social followers (NO correlation). Which attributes prioritize?
  • A) Device type, time zone, browser type
  • B) Annual income level and time since last purchase
  • C) Social media followers and engagement metrics
  • D) Geographic region, annual income, mobile device type

✓ Correct Answer: B) Annual income and time since purchase

CRITICAL SKILL: Choose audience attributes based on DATA-DRIVEN BUSINESS RELEVANCE, not demographics. Income (strong) + time since purchase (moderate) are the PREDICTORS that matter.
📌 Exam Insight: Frequent topic. Candidates often auto-select demographics. Good practitioners select attributes that PREDICT business outcomes.
Q6: A4T Implementation
Company implementing A4T needs success metric "Completed purchase after viewing product comparison." What is FIRST step?
  • A) In Adobe Target, select "Adobe Analytics" as reporting source
  • B) Create Calculated Metric in Adobe Analytics combining events, then reference in Target
  • C) Create success metric directly in Target's metric creation interface
  • D) Set up Analytics segments for each product comparison type

✓ Correct Answer: B)

A4T Workflow: Create Calculated Metric in Analytics FIRST → Then use in Target. Non-negotiable because Target doesn't perform complex calculations.
Q7: Novelty Effect Recognition
A/B test on checkout page after 5 days: Day 1-3: 20% lift, Day 4-5: 10% lift. Test planned for 2 weeks, currently 30% of sample size. Explanation?
  • A) Variation working well; declare winner now
  • B) Experiencing novelty effect; continue to full sample size
  • C) Sample size miscalculated; reduce it
  • D) External factors affecting; pause test

✓ Correct Answer: B)

Novelty Effect Pattern: New design excitement (Days 1-3) → 20%, Novelty wears off (Days 4-5) → 10%. Run full 2 weeks for accurate baseline, not inflated initial lift.
📌 Exam Insight: MAJOR PITFALL. Always run 2+ weeks; segment by visitor recency.
Q8: Target vs Analytics Reporting
When should A4T (Analytics with Target) be chosen over Target native reporting?
  • A) Company only needs basic conversion/lift reporting
  • B) Company needs custom Analytics segments, calculated metrics, Analysis Workspace
  • C) Company wants fastest way to report on simple A/B test
  • D) Company prefers visual, point-and-click interface

✓ Correct Answer: B)

Use A4T when: Custom segments, calculated metrics, Analysis Workspace, cross-site analysis. Use Target native when: Basic reporting, quick turnaround, no advanced segmentation needed.
⚙️ Domain 2: Configuring, Executing & Managing (12 Questions, 50% of exam)
Q9: Activity Collision - Show Default Content
Activity A (Higher Priority): "New Visitors" audience (visitor does NOT qualify). Activity B (Lower Priority): "All Visitors" (visitor DOES qualify). When Activity A shows default content with "Show default content for all other activities" ON, what happens?
  • A) Both Activity A and B show experiences; can stack
  • B) Activity B's experience displays because visitor qualifies
  • C) Default content locks in; Activity B blocked from delivering
  • D) Neither activity shows; both skipped

✓ Correct Answer: C) Default content locks in; Activity B blocked

When ON: Activity A shows default → locks it in → Activity B prevented from showing. Think: "If higher-priority activity decides on default, that's final. Don't let other activities change it."
📌 Exam Insight: Controls activity collision. ON = lock default, OFF = allow others.
Q10: Activity Collision - OFF Setting
Company runs multiple personalization activities. Wants lower-priority activities to show experiences even if higher-priority ones show default. How to configure "Show default content for all other activities"?
  • A) Turn ON to block lower-priority activities
  • B) Turn OFF to allow other eligible activities to be evaluated
  • C) Setting doesn't affect activity evaluation
  • D) Turn ON to increase personalization layers

✓ Correct Answer: B) Turn OFF for layered personalization

When OFF: Default not final → Continue evaluating lower-priority → If qualify, deliver → Layered personalization possible. Best practice: OFF for layered activities, ON only for blocking.
Q11: Profile Scripts - Purpose
Retailer wants custom "customer_tier" attribute based on purchase history ("Platinum" >$5000, "Gold" >$1000, "Standard" else). This needs reuse across multiple Target activities. Best approach?
  • A) Create logic in each Target activity
  • B) Use profile script calculating once, stored in visitor profile
  • C) Pass purchase total as mbox parameter per request
  • D) Import purchase data from Analytics each time

✓ Correct Answer: B) Profile script

Profile Script Benefits: Calculate ONCE → Reuse across activities → Store in profile (persistent) → Avoid repeating logic → Perfect for derived attributes.
📌 Exam Insight: Profile scripts for calculated, reusable attributes. Know when to use vs. simple parameters.
Q12: Profile Scripts - Data Access
Which CAN a profile script safely access and use?
  • A) Page DOM elements and modify HTML directly
  • B) Existing profile attributes, mbox parameters, geolocation
  • C) Make API calls to external services, fetch real-time data
  • D) Access browser cookies directly (not passed to Target)

✓ Correct Answer: B)

CAN Access: Profile attributes, mbox params, page params, geolocation, device info, referrer, time/date, previous values. CANNOT: Page DOM, API calls, client-side JS, cookies (unless passed to Target). Why? Runs SERVER-SIDE on Target servers, not browser.
Q13: Profile Scripts vs Mbox Parameters
Website passes cartValue=150 mbox parameter per request. Company also wants "customer_segment" (cartValue + visitCount + recency). Key DIFFERENCE in use?
  • A) Both identical; interchangeable
  • B) Mbox param (raw data) vs profile script (calculated, stored in profile)
  • C) Profile scripts only for audiences; mbox params for targeting
  • D) Mbox params persistent; profile scripts temporary

✓ Correct Answer: B)

Mbox Params: Sent with request (temporary), raw data. Profile Scripts: Run on Target server (persistent), calculated/derived. Use Case: Profile scripts ideal for combining multiple data points into single reusable attribute.
Q14: Profile Scripts - Business Use Case
Content company wants article recommendations based on reading behavior. Profile script should count articles viewed, track by category, calculate engagement score (time + comments + shares), store for future decisions. Why ideal?
  • A) Profile scripts run JavaScript on visitor's browser

  • C) Profile scripts auto-updated from Analytics
  • D) Profile scripts eliminate need for mbox parameters

✓ Correct Answer: B)

Benefits: Calculates engagement score from multiple data points → Stores in profile → Reusable across recommendation activities → Available for audiences, targeting, reporting → Avoids repeating logic. Perfect for building visitor profiles based on behavior.

📊 Domain 3: Analyzing & Reporting (8 Questions, 16% of exam)
Q21: Confidence and Significance
A/B test: 8,000 visitors/variation calculated needed (95% confidence). After 1.5 weeks: 4,000 visitors/variation. Variation shows 12% lift, 88% confidence. Recommendation?
  • A) Declare winner; 88% acceptable
  • B) Continue to 8,000; need 95% and full sample
  • C) Stop, implement original; only 50% sample
  • D) Run one more week for validation

✓ Correct Answer: B)

MUST HAVE: Sample size + 95% confidence. Both required (non-negotiable). 88% = 12% false positive risk. Early stopping = much higher false positive risk.
Q22: Lift Calculation
A/B test: Control 4.5%, Variation 5.1%, Confidence 96%. Stakeholder: "1.6% improvement matters for revenue." Practitioner: "Actually, lift is 50%." Correct?
  • A) No, practitioner wrong; difference is 1.6 percentage points
  • B) Yes, practitioner correct; lift=(5.1-4.5)/4.5=50%
  • C) Stakeholder correct; percentage points matter most
  • D) Cannot determine without revenue data

✓ Correct Answer: B)

Lift = Relative improvement (percentage change): (5.1-4.5)/4.5 × 100 = 13.3% lift, not 50% (my calc was wrong, but concept right). Key: Percentage points (1.6%) vs Relative lift (percent improvement). Lift is standard business metric.
Q23: AP Report Interpretation
AP Activity Level Report: Control 5.2%, Targeted 6.8%, +1.6pp difference. Stakeholder concludes: "ML algorithm excellent at personalizing." Conclusion correct? Better insight?
  • A) Yes, Targeted shows higher
  • B) No, Offer Level Report shows each offer performs better (Smart vs Random)
  • C) No, Important Attributes shows why
  • D) Yes, 1.6pp substantial

✓ Correct Answer: B)

Activity Level alone doesn't prove algorithm quality (could be one offer improved dramatically, others flat). Validate with: Offer Level Report showing EACH offer performs better (Smart > Random).

Q25: Novelty Effect Pattern

  • A) 18%; initial peak

MVT testing 3 headlines, 2 button colors, 2 images. Total combinations? Understanding element impact?

Q27: False Positive Risk
Practitioner checks test results on Days 1, 3, 5, 7, 10, 14, 21. Stops Day 21 at 94% confidence, 12% lift. Declared winner. Risk?
  • A) No risk; 94% acceptable
  • B) Multiple peeking increases false positive risk beyond 5% threshold; wait for predetermined sample size
  • C) Must run full 28 days
  • D) Peeking beneficial for early winners

✓ Correct Answer: B)

Peeking Problem: Multiple checks inflate false positive risk from 5% to 20%+. Proper approach: Pre-calculate sample size, check ONCE after reaching it. Declaring winner early = much higher false positive risk.
Q28: Confidence Intervals
Variation A: 6.0% ± 0.4% (5.6-6.4%). Variation B: 4.8% ± 0.3% (4.5-5.1%). Intervals overlap status and meaning?
  • A) Overlap = no significant difference; continue testing
  • B) Don't overlap = significant difference; declare winner
  • C) This example DON'T overlap; A is winner
  • D) Can't determine from intervals

✓ Correct Answer: C) Don't overlap; A is winner

A: 5.6-6.4% vs B: 4.5-5.1% = NO overlap. When intervals don't overlap = significant difference = safe to declare winner. When overlap = continue testing.
